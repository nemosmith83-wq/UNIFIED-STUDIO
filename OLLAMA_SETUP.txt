===== TROUBLESHOOTING =====

❌ "Ollama not found"
   → Download from https://ollama.ai and run installer

❌ "Can't connect to Ollama"
   → Open new terminal and run: ollama serve
   → Keep that window open while using Unified Studio

❌ "Mistral model not found"
   → Run SETUP_OLLAMA.bat again
   → Or manually: ollama pull mistral

❌ "Port 5000 already in use"
   → Another app is using port 5000
   → Edit START.bat to change UNIFIED_PORT=5001

===== WHAT IS OLLAMA? =====

Ollama = local AI runtime
  • Like ChatGPT but running on your computer
  • Fast (7B model = 5-10s response time on i5)
  • Private (data never leaves your machine)
  • Works offline
  • 100% open source and free

Mistral = the AI model we're using
  • 7 billion parameters (lightweight)
  • Good conversational ability
  • Fast on 8GB RAM
  • Can be swapped for other models

===== MODELS YOU CAN TRY =====

Fast (good enough):
  ollama pull mistral        (7B - recommended)
  ollama pull neural-chat    (7B - conversational)

Powerful (slower):
  ollama pull llama2         (13B - better quality)
  ollama pull dolphin-mixtral (47B - most capable)

Switch model by editing .env:
  OLLAMA_MODEL=neural-chat
