Connection and privacy

These links open Perchance in a separate tab. This app does not send your prompts, files, or account data to Perchance in the background. The plugin pages describe components for Perchance generators; no official external generation API was found, and Perchance's current Terms of Service prohibit automated or scripted access. Do not treat these links as generation integrations.

For local prompt building and saving, use Prompt Vault or PromptVault Pro. For image generation, use Image Lab. PromptVault Pro also includes the guided RVC workflow; connect only to a voice server you started and trust.
