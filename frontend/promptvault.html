About
PromptVault Pro is a completely client-side prompt library. No external API is required. Generated prompts are constructed locally from the selected template, variables, role, reasoning framework, output format, tone, and processing rules. Token estimation uses a lightweight character/word heuristic and is intended for budgeting, not exact provider billing.
