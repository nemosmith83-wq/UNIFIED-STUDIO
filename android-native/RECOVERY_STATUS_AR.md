# حالة استعادة مشروع Android من FADELOUVICH.apk

تم فحص ملف APK المرفوع واستخراج شجرة المشروع الموجودة داخل `assets/www/`.

## ما نُقل إلى المستودع

- مشروع Android الأصلي تحت `android-native/`.
- إعدادات Gradle وملف AndroidManifest.
- نشاط Android الأصلي `MainActivity.java` الذي يشغّل WebView وخادم Python محليًا.
- جسر تشغيل Python على Android `android_server.py`.
- مسار بناء GitHub Actions لإنتاج APK.
- إعداد Gradle لنسخ واجهة الويب وملفات Python الموجودة في `frontend/` و`backend/` إلى حزمة Android وقت البناء.

## ما لم يُنقل إلى المستودع بعد

- النسخة الكاملة من واجهة الويب المضمّنة داخل APK؛ حجمها كبير وتتضمن ملفات ثنائية وموارد متعددة.
- ملفات الصور المرجعية الشخصية الموجودة في مجلدات الشخصيات. لم تُرفع إلى مستودع عام.
- ملفات النماذج وأوزان Stable Diffusion ومحرك ARM64؛ لم تكن موجودة داخل APK.
- واجهة Local Diffusion تشير إلى خدمة محلية على المنفذ 8766، بينما خادم Android الحالي يستمع على 8765 ولا يحتوي بعد على مسارات `/sdcpp/v1`. لذلك التوليد المحلي غير مفعّل.

## البناء

يُنفّذ GitHub Actions بناء Android Debug APK. نجاح البناء وحده لا يثبت أن كل وظائف التطبيق تعمل على الهاتف؛ يلزم بعده تثبيت APK واختبار التشغيل وتدفقات الاستخدام الفعلية.
